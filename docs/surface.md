# 调色工作台
Mode: Operate。扩展当前工作区地图工具的蓝灰界面语汇；独立目录，不更改地铁图。
## Direction contract
THESIS: 地图是主体，道路颜色和线宽是直接操作对象。
OWN-WORLD: 沿用现有地图工具系统字体、蓝灰控件和地图占主空间的语言，浅色控制面板适合桌面调色；地图颜色全部可改。
STORY: 打开即显示真实道路，按等级修改，缩放看细节，保存配色并导出。
FIRST VIEWPORT: 顶部标题与导出，左侧约300px图层列表，右侧16:10地图画布，下方数据体积与来源。道路每行包含颜色、开关和线宽；面图层每行包含颜色、开关和不透明度；机场设施沿用这套控件，独立控制跑道、滑行道和停机坪。预设有4个内置与6个用户指定MapToPoster主题。导出只有地图像素，默认3840×2400，支持7680×4800分块原生渲染。
FORM: 用户明确指定地图调色工具，沿用现有世界；窄任务直接塑形，无概念抽签。
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
