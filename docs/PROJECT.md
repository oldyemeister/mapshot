# Mapshot 第一阶段项目说明

更新日期：2026-10-28。目标目录：`/Users/jacky/Documents/mapshot`。

## 目标与验收

让少量朋友收到网址后，无需安装软件即可完成：打开上海地图 → 选择主题 → 修改图层 → 下载图片。

本阶段交付可复制的前端、轻量 Python 服务、运行包与文档。用户暂未提供树莓派连接信息及公网入口，所以实际树莓派部署、公网链接和真实朋友试用仍待完成，不能写成已上线。

验收项目：

- 桌面与 390px 窄屏可打开，页面没有横向溢出。
- 首次读取显示实际读取量，读取完显示绘制阶段；失败给出可操作的重试按钮。
- 主题、道路颜色/宽度/可见性、建筑与其他面图层设置即时生效。
- 配色自动保存在当前浏览器，可导入导出 JSON；旧配色仍能读取。
- 桌面验证 3840×2400，窄屏验证 1920×1200 PNG，导出结束恢复交互。
- 服务只发布运行资产，原始地图与开发文件不能通过 HTTP 访问。
- 使用部署包启动时不需要 Node、pip 安装、数据库或外部地图 API。

## 已选择的架构

前端使用现有 HTML/CSS/JavaScript 与 MapLibre GL JS 5.10.0。Python 标准库提供静态文件和只读接口：`GET /api/health`（进程状态）、`GET /api/dataset`（地图数据清单）。两者支持 HEAD。

后端不接受用户代码、不接收上传、不进行图片渲染。调色、配置校验、localStorage 保存和 PNG 生成在用户浏览器完成。没有后台管理页面；运营者通过文件和启动命令管理本次固定数据快照。

此阶段没有 SQLite。SQLite 将在需要跨设备作品保存时引入，存作品配置与元信息，不存地图像素或整个地理数据库。FastAPI 在需要写入接口、账号或任务 API 时引入；Vite/TypeScript 在前端模块化重构时评估，避免仅为部署重写成熟编辑器。

## 数据与加载现状

保留上海及周边真实 OSM 数据；原始数据快照见 `data/manifest.json`，航空设施使用不同日期的快照，不能混写为统一日期。

当前五个压缩 GeoJSON 合计约 35.27 MB，完整运行资源约 45.15 MB（源码变化会使小数变化）。首次打开仍会读取全部五个几何图层；海域缓存按视野请求。关闭图层只隐藏显示，不减少本次几何下载。这一版尚未实现 PMTiles 或按勾选项下载。

`.geojson.gz` 由应用解压；试用服务器以 `application/gzip` 发送文件，不设置 `Content-Encoding: gzip`。浏览器缓存通过 Last-Modified/条件请求重新验证。加载后释放临时 Blob URL；地图内部仍需持有几何数据。

仅传输 35.27 MB，在单用户理想 10 Mbps 链路上约需 28 秒，20 Mbps 约需 14 秒，另需下载组件、解压和绘制；这只是字节数计算，不是实测速率。服务器 CPU 较轻并不等于用户手机内存负担小。

下一步依据真实网络和设备测试判断是否迁移为道路、建筑、水域等独立 PMTiles。瓦片生成需要检查小路、小建筑、孔洞、缩放细节和导出效果，不能以降低地图质量掩盖性能问题。

## 部署与迁移

开发目录完整迁移为 `Documents/mapshot`；独立的地铁项目仍有自己的目录。原始数据、历史产物与旧开发环境保留在开发目录中，但复制到树莓派时只需 `dist/mapshot-trial.zip`。

树莓派 5 约 4GB 内存，初期仅给自己与朋友试用。运行环境为 Python 3.9+；无需桌面环境或 GPU 服务端渲染。优先使用 64 位系统、有线网络及稳定散热供电。实际内存、存储、上传带宽与公网方式仍需用户确认。

## 时间与费用

复用现有项目，演示版原估算为 2–4 个有效开发日；更完整朋友试用版估算 6–12 个开发日。它们是范围估算，不是计费账单或已经花费的时间；新需求需重新评估。

运行软件没有额外许可费，复用现有树莓派与开发电脑。域名、转发、额外存储和 AI 额度按实际选择计费，本阶段没有购买或开通任何付费服务。

## Git 与文档分工

现在已适合开始 Git。源码、文档、脚本、小型清单进入 Git；原始地图、运行几何大文件、环境、PNG 和 ZIP 排除。首次克隆需另取匹配的数据包；Git 本身不能替代地图数据备份。

- `README.md`：给使用者和开发者的入口。
- `PRODUCT.md`：用户、用途、功能范围与约束。
- `DESIGN.md`：现有界面设计规范。
- `AGENTS.md`：给编程代理的持续工作约定，不是程序入口，不会自行运行，也不会创建多个 AI。
- `docs/PROJECT.md`：架构取舍、里程碑与后续方向。
- `docs/DEPLOYMENT.md`：实际启动、拷贝与排查操作。

建议本地初始化后先检查 `git status` 和暂存清单再提交；发布 GitHub 属于独立动作。无需为了开始本地版本记录购买服务或创建远程仓库。
